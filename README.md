# AstraMindAI

AstraMindAI is a multi-agent, safety-aware AI assistant platform with:

- TypeScript backend (REST API, auth, models, settings).
- React + Vite frontend.
- Python ML service for custom models.
- Worker for background jobs and analytics.

## Getting Started

```bash
pnpm install
cp .env.example .env.development
pnpm dev
```
