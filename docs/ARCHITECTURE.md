# Data Governance

AstraMindAI follows strict data governance principles:

- **Classification** — Data is categorized by sensitivity.
- **Retention** — Data is retained only as long as necessary.
- **Access Control** — Least-privilege access enforced across services.
- **Anonymization** — Sensitive data is anonymized where possible.
- **Compliance** — GDPR, CCPA, SOC2-aligned policies.
